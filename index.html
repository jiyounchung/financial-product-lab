PROJECT 01 — FEATURED

ONE CHECK CARD
Personalized Cashback Intelligence

고객 소비 패턴 기반 체크카드 혜택 선택 최적화. 케이뱅크 ONE 체크카드 구조를 참고한 서비스 개선 기획입니다.

상품 조건 안내. 작성 환경에서 공식 상품설명서에 접근해 확인하지 못했습니다. 아래 혜택률·한도·실적 기준은 실제 조건이 아닌 가정값이며 단순화된 추정 시뮬레이션입니다. 실제 조건은 공식 상품설명서(기준일 확인 필요)를 따르세요.

PROJECT 02 — PRODUCT ANALYTICS

Understanding Spending Behavior
체크카드 이용 데이터 분석 및 상품 성과 관리

Synthetic Data. 가상 고객 1,000명의 3개월(2026-07~09) 결제 데이터를 시드 20261115로 생성했습니다. 실제 고객 데이터가 아닙니다. 건별 캐시백은 한도·전월실적을 반영하지 않은 단순화 값입니다.

지표 정의 (분모·계산 기준)
  • 활성 고객 수: 조회 기간 내 결제 1회 이상 고객-월 쌍의 수 ÷ 조회 월 수
  • 고객당 월평균 결제금액: 결제금액 합 ÷ 활성 고객-월 쌍 수
  • 고객당 월평균 결제 횟수: 결제 건수 ÷ 활성 고객-월 쌍 수
  • 평균 객단가: 결제금액 합 ÷ 결제 건수
  • 비용률: 캐시백 합 ÷ 결제금액 합

From Insight to Impact

A/B Test Framework (설계안, 결과 없음)
구분내용
그룹Control: 기존 캐시백 선택 화면 / Treatment: 소비 데이터 기반 추천 화면
가설추천 화면이 혜택 선택 완료율을 높일 것이다(가설)
무작위 배정고객 ID 해시 기반 50:50, 신규 발급 고객 대상
기간 기준사전 표본 수 산정 후 주간 패턴을 포함하는 2주 단위 정수 배수
1차 지표혜택 선택 완료율, 신규 발급 30일 내 첫 결제율
2차 지표월간 활성 이용률, 고객당 결제금액
가드레일캐시백 비용률, 고객 문의·불만 발생률
판단 기준성공: 1차 지표 유의한 개선 + 가드레일 사전 기준 이내 / 실패: 가드레일 초과 또는 개선 없음
